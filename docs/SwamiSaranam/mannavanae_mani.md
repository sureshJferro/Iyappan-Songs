# **மன்னவனே மணிகண்டனே மாயன் பெற்ற புத்திரனே**

மன்னவனே மணிகண்டனே மாயன் பெற்ற புத்திரனே      </br>
மகிசியை அழிப்பதற்கு மண்ணில் வந்து பிறந்தவனே       </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
														</br>
பந்தளத்தில் வீடு இருக்க பச்சைநெல்லு சோறு இருக்க      </br>
பாண்டு ரெங்கன் பெற்ற பிள்ள நீ பட்டினியா போகலாமோ </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
														</br>
யானை கழுத்தினிலே அலங்கார மணி விளக்கு            </br>
பார்க்க வரும் பக்தனுக்கு பாலகனாம் காட்சி தந்தாய்      </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
														</br>
மதுரை குங்குமம் வச்சி மண்டையில் கட்டும் கட்டி         </br>
முன்னால இருக்கும் முடி அது உன்முடியாம் திருமுடியாம்   </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
														</br>
அஞ்சு வகை பவுடர் பூசி ஆடிவாரோம் பாடிவாரோம்       </br>
பாக்காத சாமி எல்லாம் பாத்து வணங்கி வாரோம்         </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
														</br>
ஊரு மறந்து வாரோம் உன் புகழ் சொல்லி வாரோம்        </br>
தாயாரை வணங்கிவாரோம் தயவுடனே வாருமைய்யா      </br>
வீரமணிகண்டா நீ இக்கட, இக்கட ரெண்டா (2)           </br>
